# Grid images

Lägg bilderna för startsidans pixel-grid i den här mappen.

Aktuella filnamn som `js/main.js` förväntar sig:

- `detaljplaner.jpg`
- `projects.jpg`
- `rosengard.jpg`

När du lägger till en ny grid-ruta:

1. Lägg bildfilen i `grid/`.
2. Lägg till projektet i `gridProjects` i `js/main.js`.
3. Ange bara filnamnet i `imageName`, inte hela sökvägen.
